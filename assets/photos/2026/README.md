# Mahamana Hockey Gold Cup — 2026 Photo Uploads

This folder is for the **original 2026 tournament photographs** that will be displayed in the website's 2026 gallery.

## Uploading
1. Open this folder on GitHub and select **Add file → Upload files**.
2. Drag and drop the 2026 JPG/JPEG/PNG photos from your computer.
3. Use **Commit changes** to save.

Please keep original filenames unchanged for matching images to gallery categories. The website's photo albums will only be updated after these images are uploaded and checked.

**Videos:** Do not upload large original MP4s here. Several source clips exceed GitHub's 100 MB single-file limit. They need a video host or compressed web versions before website integration.
